# go-ride-billing

🚕 **GoRide Tirupati Cabs — Instant Duty Slip & Invoice Generator**

A mobile-first, client-side React billing and duty slip generator designed specifically for **GoRide Tirupati Cabs** (`www.goridetirupatitravels.in`).

---

## 🌟 Key Features

- **📱 Mobile-First Experience**: Optimized for smartphone use by proprietor on the go with dedicated 2-step navigation (`1. Fill Details` / `2. View Bill`) and sticky bottom actions (`Download PDF`, `WhatsApp Share`).
- **📄 Clean Single-Page A4 PDF**: Generates crisp, executive-grade duty slips & invoices formatted perfectly for A4 printing and PDF export with zero awkward second-page breaks.
- **🚕 Official GoRide Fleet & Tariffs**:
  - Swift Dzire (Sedan 4+1) @ ₹14 / km
  - Maruti Ertiga (MUV 6+1) @ ₹19 / km
  - Innova Crysta (Luxury MPV 7+1) @ ₹23 / km
  - Tempo Traveller (Minibus 12-14 Seater) @ ₹28 / km
- **🛕 9 Popular Tour Packages & 13 Sacred Sights**:
  - Auto-fills distances and hours for Tirumala 1-Day, Airport Transfers, Kanipakam • Golden Temple • Arunachalam, 5 Temples Circuit, Srikalahasti, etc.
  - Collapsible selector for all 13 Hilltop & Valley sacred landmarks.
- **💬 1-Tap WhatsApp Billing**: Sends customer instant, formatted trip summary with balance due and proprietor contact via WhatsApp.
- **💳 UPI QR & Payment Breakdown**: Dynamic UPI QR code (`8500953558@ybl`), cash / bank modes, advance payment tracking, and balance due indicators.
- **🔒 Zero Backend**: Entirely client-side with draft persistence in browser `localStorage`.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/GOride-cabs/go-ride-billing.git

# Navigate to project folder
cd go-ride-billing

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
